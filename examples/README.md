# Examples

Three fully generated setups showing what `build-my-focus-engine` produces for three different people, tools and plans. Each folder has the setup conversation, the filled-in Assistant Profile, every installed helper, the handover card, and a sample delivery from each helper. The people are described in [PERSONAS.md](PERSONAS.md); every name, company, address and number is invented.

| | [Maya Chen](maya-chen-sales-vp/) | [Darnell Brooks](darnell-brooks-nonprofit-ed/) | [Priya Raman](priya-raman-solo-consultant/) |
| --- | --- | --- | --- |
| Role | VP of Sales, 40-person SaaS | Executive Director, 12-person nonprofit | Solo brand consultant |
| Tool · plan | Claude · Max | Microsoft 365 Copilot · nonprofit license | ChatGPT · Plus |
| Sources | Slack, Gmail, Calendar, Drive, HubSpot | Outlook, Teams, Calendar, OneDrive | Gmail, Calendar, Drive |
| Helpers | Brief, meeting prep, shutdown, audit | Brief (prep folded in), shutdown, audit | Brief (prep folded in), shutdown, audit |
| Scheduled runs | 4 tasks (brief, hourly prep, shutdown, every-other-Friday audit) | 2 of 10 scheduled prompts | 2 tasks (4 of 5 slots with her own) |
| Delivered to | Slack DM | Copilot chat + email notification | Task conversation + push |
| Feedback | Thread replies and reactions | Pending updates box in the Profile | Replies + Pending updates box |
| Verification | Fresh sub-agents | Separate re-check pass | Separate re-check pass |
| Profile | Google Doc, written by helpers | Word doc in OneDrive, read only | Google Doc, read only |
| Automatic | Everything, including Profile updates | Brief and shutdown runs | Brief and shutdown runs |
| Manual | One "Always allow" per task; shutdown reply | Paste updates daily; Friday tidy in Word; send nudges; run the audit | Paste updates daily; Thursday tidy; book focus blocks; run the audit |

Start with Maya to see the full engine, then Darnell and Priya to see how setup designs around a read-only Profile and a task cap without the helpers ever mentioning it.
