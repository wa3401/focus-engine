# Install guides

One file per tool. Each says: where helpers can live, how scheduling works, known limits, and the lowest-effort install path.

**Trust preflight over these files.** Plan limits change often. Each fact below is tagged:

- **[verified YYYY-MM]** — read on the vendor's official docs at that date.
- **[unverified]** — from secondary sources; confirm in the product during preflight (ask the user to open the relevant settings page if you can't see it).

If preflight contradicts a guide, follow preflight and tell the maintainer (open an issue) so the guide gets fixed.
