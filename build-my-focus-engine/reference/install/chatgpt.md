# Installing on ChatGPT

All facts here are **[unverified]** as of 2026-11 — confirm in preflight.

## Where helpers live

- **Tasks** — scheduled prompts. Reported active-task caps vary by plan (roughly 3 on Free/Go, 5 on Plus, 10–15 on Business/Pro/Enterprise), at most hourly. Results arrive in-app with push/email notification. Reports say tasks can't use custom GPTs or Project files → put the **full helper instruction in the task prompt itself**.
- **Connected apps** (Gmail, Calendar, Drive, etc.) may be usable inside tasks on paid plans; sending may ask for confirmation. Preflight tests both.
- **Skills / custom GPTs / Projects** — optional for on-demand use. GPT instructions reportedly cap around 8,000 characters; custom instructions around 1,500 (free) to 5,000 (paid). Keep on-demand helpers lean or attach reference files.

## Lowest-effort path

1. If the task cap allows, one task per helper; otherwise merge (e.g. one morning task that includes meeting prep; shutdown as a second; audit on demand).
2. Profile: read via a connected Drive doc if available. If tasks can't write back, end each delivery with the "Profile updates" block; the user applies it in the next chat.
3. Verification: if sub-agents aren't available, use the separate re-check pass.
4. Delivery: in-app (default). Feedback: reply in the task's chat thread.

## Free plan

Use `manual.md` if tasks aren't available or the cap is used.
